# Artwork provenance

All shoe photography and page artwork were supplied by the project owner through the approved Jang Sport Center Night Match design pack (`outputs/night-match-v3`). The website reuses those exact compositions. No new product models, outsole compatibility, or performance specifications have been inferred from the generated photography.

The website files are WebP encodings of the complete approved PNG images. They retain the original canvas dimensions and are displayed through CSS image windows where an isolated artwork region is needed. No image was creatively retouched during this conversion. Keep the original design pack as the high-resolution source archive.

## Self-hosted fonts

Fonts were downloaded from the official Google Fonts CSS endpoint and its `fonts.gstatic.com` font CDN on 27 October 2026. Only the Latin subsets required by the Bahasa Melayu / English interface are included.

- `fonts/barlow-condensed-bold-italic.woff2`: Barlow Condensed, italic, weight 800.
- `fonts/barlow-condensed-semibold.woff2`: Barlow Condensed, normal, weight 600.
- `fonts/inter.woff2`: Inter variable, normal, weights 400–700.

These fonts use the SIL Open Font License. Complete license texts are retained alongside the fonts as `barlow-condensed-OFL.txt` and `inter-OFL.txt`, downloaded from `https://github.com/google/fonts/tree/main/ofl/barlowcondensed` and `https://github.com/google/fonts/tree/main/ofl/inter`.
